V2RAY · WINDOWS CLIENT

v2rayN 使用指南

Windows 平台原生 V2Ray / Xray 核心客户端安装、配置导入与分流手册
快速配置流程
1. 下载并运行客户端
v2rayN 是 Windows 平台经典成熟的开源客户端，内置 Xray 内核与完整图形界面。
  • 官方开源发布页：访问 GitHub Releases 页面：2dust/v2rayN Releases
  • 下载推荐：建议下载包含核心的完整压缩包，如 v2rayN-With-Core.zip 或 v2rayN-windows-64-desktop.zip。
  • 解压与运行：下载完成后右键“全部解压缩”至独立文件夹（建议非 C 盘根目录），双击 v2rayN.exe 启动。
2. 获取与导入专属订阅
按以下步骤先获取节点专属订阅链接，随后导入 v2rayN 以拉取可用服务节点：
  1. 获取节点订阅链接（必选）：
    前往 购买高速专线节点 ↗。支付成功后即可在 邮箱 中获取 专属订阅链接，格式如下：
    https://sub.freeshop.lol/sub/xxxxxxxxxx
  2. 启动客户端，导入订阅链接：
    • 启动 v2rayN 后，点击主界面顶部菜单栏的 “订阅分组” ➔ “订阅分组设置”。
    • 在弹出的窗口左下角点击 “添加”：
      • 别名：填写任意备注名称（如 MyService）。
      • 可选地址 (Url)：粘贴刚才拿到的专属订阅链接。
    • 点击右下角 “确定” 保存设置。
    • 回到主界面，点击顶部菜单 “订阅分组” ➔ “更新全部订阅(不通过代理)”，节点列表将自动呈现在窗口中。
3. 系统代理与分流模式设置
在任务栏右下角托盘区，右键点击 v2rayN 图标确认以下关键设置：
系统代理➔自动配置系统代理
图标变红，浏览器及绝大多数日常应用自动接入代理
路由规则➔绕过大陆 (Whitelist)
国内常用网站直连，海外网站走专线（最推荐）
开机自动启动➔勾选开启
登录 Windows 系统后自动在后台托盘静默运行
4. 批量测速与切换连接
选择网络连通性最佳的节点启动使用：
快捷测速：在主界面节点列表按 Ctrl + R，立即测试所有节点真实延迟。
  • 测试完成后，列表中会显示真实延迟数值（绿色数值为优，如 118ms）。
  • 单击选中该节点，按键盘 Enter 回车键设为活动节点（左侧出现对勾即为生效）。
  • 打开浏览器访问海外站点测试，连接建立即表示配置成功。
常见问题与排错指引
网页无法加载
右键托盘图标确认“系统代理”是否已选为“自动配置系统代理”；检查节点延迟是否为正数。
国内网站访问变慢
检查托盘菜单“路由”是否被误设为全局。请务必选择“绕过大陆”以保证国内流量直连。
订阅更新失败
检查网络是否通畅；部分网络环境更新订阅时可尝试右键选中代理先开启后再更新。
系统时间不同步
现代加密传输要求本地系统时间误差不得超过 90 秒，若提示握手错误请在 Windows 设置中同步时间。
V2RAY · ANDROID CLIENT

v2rayNG 使用指南

安卓平台轻量级 V2Ray / Xray 原生客户端安装、订阅拉取与分应用分流手册
快速配置流程
1. 安装包下载与系统授权
v2rayNG 是安卓平台装机量最大、兼容性最出色的 V2Ray 客户端。
  • 官方开源发布页：访问 GitHub Releases 页面：2dust/v2rayNG Releases
  • 安装包选择：推荐下载主流 64 位包 v2rayNG_x.x.x_arm64-v8a.apk 或通用包 universal.apk。
  • 下载后在手机系统文件管理中打开，允许“从未知来源安装”并完成安装。
2. 获取与导入专属订阅
按以下步骤先获取专属订阅链接，随后填入 v2rayNG 以拉取可用节点：
  1. 获取节点订阅链接（必选）：
    前往 购买高速专线节点 ↗。支付成功后即可在 邮箱 中获取 专属订阅链接，格式如下：
    https://sub.freeshop.lol/sub/xxxxxxxxxx
  2. 启动客户端，导入订阅链接：
    • 打开 v2rayNG，点击左上角 “三”（侧边栏菜单），选择 “订阅分组设置”。
    • 点击右上角 “+” 号新建订阅分组：
      • 备注：输入任意便于辨别的名称。
      • 可选地址 (Url)：粘贴刚才拿到的专属订阅链接。
    • 点击右上角对勾图标保存。
    • 返回主界面，点击右上角 “三点” 菜单，选择 “更新订阅”，所有节点将自动加载呈现。
3. 核心分流与应用代理设置
点击左侧抽屉菜单进入 “设置”，按以下规范调优：
路由模式➔绕过局域网及大陆地址
微信、淘宝等国内流量直连，海外流量走代理（最推荐）
分应用代理➔按需开启
可自由勾选仅允许特定海外 App 走代理通道
开机自启➔建议开启
手机重启后在后台自动恢复连接，省去重复手动点击
4. 批量测速与启动连接
挑选延迟最佳的节点并建立连接：
  • 点击右上角三点菜单 ➔ 选择 “测试全部配置真连接延迟”。
  • 列表中节点右下角将呈现绿色延迟（如 140ms），轻触选中该节点（左侧边缘变高亮）。
  • 轻按右下角圆形的 “V” 字主开关。
  • 首次启动时，系统会弹出“网络连接请求 (VPN)”授权提示，点击“确定”。主开关变红即表示已正常连接。
常见问题与排错指引
后台经常断连
各大厂商系统（如小米澎湃、华为、OPPO）容易杀后台，请在系统设置中为 v2rayNG 关闭“电池优化”，并加入自启动白名单。
国内应用加载慢
请确认“设置”中的路由模式选为了绕过局域网及大陆地址，切勿设置为全局代理。
测速全部显示 -1
负数代表握手超时，可尝试切换 Wi-Fi / 数据网络，或检查订阅链接是否已过期。
节点订阅导入报错
粘贴订阅链接时请勿包含多余的前后空格或特殊转义字符，确认链接以 https:// 开头。
V2RAY · IOS CLIENT

V2BOX 使用指南

iPhone 与 iPad 平台原生轻量 V2Ray 客户端安装、订阅拉取与连接手册
快速配置流程
1. App Store 下载与安装
V2BOX 是专为 V2Ray / Xray 生态打造的 iOS 原生网络工具，界面简洁现代化。
  • 应用商店：在非国区（如美区、日区、港区等）App Store 登录海外 Apple ID。
  • 搜索下载：在 App Store 搜索 V2BOX - V2ray Client 直接获取下载。
  • 安装完成后即可切回个人常用国区账号，不影响已安装应用的使用与本地配置。
2. 获取与导入专属订阅
按以下步骤先获取专属订阅链接，随后导入 V2BOX 以同步可用节点：
  1. 获取节点订阅链接（必选）：
    前往 购买高速专线节点 ↗。支付成功后即可在 邮箱 中获取 专属订阅链接，格式如下：
    https://sub.freeshop.lol/sub/xxxxxxxxxx
  2. 启动客户端，导入订阅链接：
    • 打开 V2BOX，点击底部导航栏第二个图标 “Configs”（节点配置）。
    • 点击右上角的 “+” 加号按钮。
    • 在弹出的菜单中选择 “Add Subscription”（添加订阅）。
    • 填写配置：
      • Subscription Name：填入任意名称（如 MyService）。
      • Subscription URL：粘贴刚才拿到的专属订阅链接。
    • 点击右上角 “Add” 保存，客户端将立即自动同步并展开节点列表。
3. 分流规则与常用设置
点击底部导航栏 “Settings”（设置），建议按以下规范配置核心开关：
Routing 路由规则➔Bypass Mainland
绕过大陆域名及 IP，国内直连不耗流量（最推荐）
Auto Update Subscriptions➔开启 (ON)
开启后每次启动应用自动拉取最新节点与可用列表
Sniffing 流量探测➔开启 (ON)
精准识别真实访问域名，防止本地 DNS 劫持与污染
4. 测速与建立连接
选择可用节点并开启 iOS 系统 VPN：
  • 在 Configs 页面，点击右上角仪表盘或 “Ping All” 按钮批量测速。
  • 测速完成后点击选中延迟较低的节点（节点旁显示对勾或高亮）。
  • 点击底部第一个图标返回 “Home” 首页。
  • 点击中间醒目的 “Slide to Connect” 滑动条或连接按钮。
  • 初次连接时 iOS 会弹出“添加 VPN 配置”授权提示，点击“允许”并输入手机锁屏密码。状态变为 Connected 即连接成功。
常见问题与排错指引
网络连接授权
首次打开若弹出“是否允许使用无线局域网与蜂窝网络”，必须点击允许，否则客户端无法联网拉取订阅。
连上后国内软件打不开
请进入 Settings 确认 Routing 规则选为了 Bypass Mainland，避免国内服务走海外代理。
Ping 测速全部超时
可能是本地网络连接受阻，尝试关闭 Wi-Fi 使用 4G/5G 移动蜂窝数据测试，或刷新订阅。
系统时间准确性
iOS 设备通常自动对时，如曾手动调快时间可能导致连接失败，请在 iPhone 设置中开启“自动设置时间”。

Shadowrocket (小火箭) 使用指南

iPhone 与 iPad 平台老牌多协议代理客户端安装、订阅拉取与分流手册
快速配置流程
1. App Store 下载与安装
Shadowrocket 是 iOS 平台最广为人知的专业代理工具，协议兼容性极佳。
  • 在 App Store 中退出当前账号，登录非国区（美区/港区等）Apple ID。
  • 在 App Store 搜索 Shadowrocket（认准白底蓝色小火箭图标）。
  • 完成下载安装后，可退出并换回个人主力国区账号。
2. 获取与导入专属订阅
按以下步骤先获取节点专属订阅链接，随后导入小火箭以同步节点列表：
  1. 获取节点订阅链接（必选）：
    前往 购买高速专线节点 ↗。支付成功后即可在 邮箱 中获取 专属订阅链接，格式如下：
    https://sub.freeshop.lol/sub/xxxxxxxxxx
  2. 启动客户端，导入订阅链接：
    • 打开 Shadowrocket，轻点右上角的 “+” 号。
    • 将“类型”项切换为 Subscribe（订阅）。
    • 在“URL”一栏粘贴刚才拿到的专属订阅链接；“备注”填入任意名称。
    • 点击右上角 “保存” (Save)，客户端将立即开始下载并呈现所有节点。
3. 全局路由策略设置
在应用主界面中间及设置中，确认以下推荐配置：
全局路由➔配置模式 (Config)
国内网站直连，海外流量智能分流走专线（最推荐）
代理模式 (Proxy)➔仅排错时启用
强制所有应用流量走海外节点，日常无需开启
打开时更新订阅➔开启 (ON)
在下方“设置” ➔ “订阅”中开启，自动拉取最新节点
4. 连通性测试与启动
选择可用节点并拨动连接开关：
  • 在节点列表上方点击 “连通性测试”，数值显示为绿色（如 125ms）的节点代表网络可用。
  • 轻触选中目标节点（左侧出现橙色圆点标记）。
  • 拨动主界面最顶部的 “未连接” 开关至开启状态。
  • 系统弹出“添加 VPN 配置”弹窗时，点击“允许”并输入手机锁屏密码确认即可。
常见问题与排错指引
首次启动网络受限
首次打开提示“网络权限”时若误点了不允许，请前往 iOS“设置” -> “Shadowrocket”中重新开启“无线局域网与蜂窝数据”。
微信/网银无法连接
确认全局路由是否被误设为了“代理”。只有保持为“配置”模式，国内流量才会被安全分流直连。
订阅更新超时
可在节点上向左滑动选择“更新”，或长按订阅分组名称选择“更新”。
证书或时间报错
V2Ray 协议对时间敏感，若遇握手超时请在 iOS“设置” -> “通用” -> “日期与时间”中开启“自动设置”。

V2rayU 使用指南

macOS 平台原生菜单栏 V2Ray 客户端安装、配置导入与系统代理设置手册
快速配置流程
1. 安装包下载与 Mac 权限授权
V2rayU 专为 macOS 打造，常驻顶部菜单栏，极简轻巧。
  • 官方开源发布页：访问 GitHub Releases 页面：yanue/V2rayU Releases
  • 架构选择：Apple M 系列芯片机型请选择 V2rayU-arm64.dmg；Intel 芯片机型请选择 V2rayU-64.dmg。
  • 双击挂载 DMG，将 V2rayU.app 拖入 Applications（应用程序）文件夹。
  • 若首次启动弹出“无法打开，因为无法验证开发者”，前往 Mac 系统设置 -> 隐私与安全性，在页面底部点击“仍要打开”即可。
2. 获取与导入专属订阅
按以下步骤先获取节点专属订阅链接，随后在 Mac 顶部菜单栏中添加以同步节点：
  1. 获取节点订阅链接（必选）：
    前往 购买高速专线节点 ↗。支付成功后即可在 邮箱 中获取 专属订阅链接，格式如下：
    https://sub.freeshop.lol/sub/xxxxxxxxxx
  2. 启动客户端，导入订阅链接：
    • 启动后，在 Mac 屏幕最上方菜单栏找到 “U” 字形小图标，点击它。
    • 在下拉菜单中选择 “订阅设置” (Subscribe Setting)。
    • 在弹出窗口中：
      • 地址 (Url)：粘贴刚才拿到的专属订阅链接。
      • 备注 (Remark)：输入任意便于辨别的名称。
    • 点击右侧 “添加” (Add)，随后点击 “更新” (Update)，节点将自动拉取呈现。
3. 模式切换与代理开关
点击屏幕顶部菜单栏“U”字图标，建议确认以下设置：
Turn v2ray-core On➔点击开启
启动内核服务并接管 Mac 系统代理（菜单显示 Off 时代表正在运行）
运行模式➔PAC Mode (PAC 模式)
智能分流模式，国内网站直连，海外网站走专线（最推荐）
开机自动启动➔勾选开启
登录 macOS 桌面后自动在顶部菜单栏常驻运行
4. 节点测速与选择
在菜单栏快速选择可用服务器：
  • 点击菜单栏 “U” 图标 ➔ 点击 “Server”（服务器列表）。
  • 点击 “Ping all servers” 可检测各个节点的真实网络连通延迟。
  • 点击选中延迟为绿色的优质节点（勾选即生效）。
  • 确保菜单中显示为 “Turn v2ray-core Off”（代表当前处于开启状态，点击可关闭）。
  • 打开 Safari 浏览器访问目标站点进行连通验证。
常见问题与排错指引
退出后 Mac 无法上网
若异常强制退出导致系统代理未重置，请进入“系统设置” -> “网络” -> “Wi-Fi 详细信息” -> “代理”，取消勾选网页代理 (HTTP/HTTPS)。
国内网站加载缓慢
请确认运行模式为 PAC Mode，若误设为 Global Mode 会导致国内流量绕道海外。
菜单栏图标不显示
刘海屏 MacBook 可能会遮挡过多菜单栏图标，可通过“活动监视器”或第三方菜单栏管理工具查看。
系统时钟校验错误
macOS 通常默认自动同步苹果时间服务器，如曾手动调整时间导致偏差过大将无法握手，请保持时间自动同步。
